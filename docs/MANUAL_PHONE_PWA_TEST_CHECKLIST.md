# Manual Phone & PWA Test Checklist

Steps Josh should perform on a real phone against the production Vercel site:

1. Open the production Vercel URL in mobile browser
2. Install the PWA (Add to Home Screen)
3. Launch the app from home screen
4. Verify portrait layout across key pages: Dashboard, Modules, Scenarios, Roleplays
5. Test navigation: open menu, navigate between pages
6. Switch career modes (School / MSP / Generic) and confirm UI updates
7. Complete a module and confirm progress increments
8. Complete a scenario run, submit ticket note, and verify evidence package can be downloaded
9. Use a roleplay interaction and validate audio/text flows (if applicable)
10. Export progress; save the file to device
11. Turn device offline, launch app, confirm offline shell loads
12. Reconnect and confirm progress syncs/retains
13. Check text size, tap targets, and that scrolling behaves correctly
14. Capture screenshots for any issues and include route and timestamp

Record results in the app's QA sheet with the following columns: route, action, result, screenshot link, notes.
