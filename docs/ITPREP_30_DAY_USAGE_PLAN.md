# ITPrep 30-Day Usage Plan (practical)

Goal: Use the app daily/weekly to practice MSP workflows and reinforce learning.

Week 1 — Orientation & quick wins
- Day 1: Set `Career Focus` to MSP and explore dashboard recommendations (30m)
- Day 2: Complete 1 MSP module (45–60m)
- Day 3: Run 1 MSP scenario; submit a ticket-note and save evidence pack (30–45m)
- Day 4: Roleplay session (20–30m)
- Day 5: Review 2 cheat-sheets and make personal notes (20m)
- Weekend: Reflect in journal (what improved, what was hard)

Week 2 — Build routine & triage practice
- Complete 2 scenarios focused on network and printer issues
- Practice ticket-note writing: compare with `ticketNoteExample` and improve
- Run a roleplay with teammate or self-record audio for feedback

Week 3 — Deepen skills & evidence collection
- Focus on RMM alerts and evidence-pack assembly
- Export progress snapshot, clear local progress, import and verify restore
- Review `CLIENT_OFFICE_SUPPORT_LAB_SPEC.md` and simulate one lab incident

Week 4 — Assessment & reflection
- Take a timed assessment (strict quiz or scenario series)
- Collect top 3 recurring mistakes and create micro-lessons
- Create a personal action plan for next 30 days

Daily micro-practices (10–15 minutes)
- Read a cheat-sheet
- Answer 1 flashcard or MCQ
- Add one improvement to ticket-note templates

Guidance for use during quiet work periods
- Replace low-value tasks with a 20–30 minute scenario run
- Use roleplays to practise communication during slow hours
- Use evidence-pack snapshots to mock vendor escalations

Reflection prompts (weekly)
- What was unclear this week?
- Which ticket notes were accepted as high-quality?
- What did you learn about escalation decisions?
