# Final Content & Privacy Review Checklist

Checks to run before publishing MSP content:

- Synthetic names only: confirm all client and user names are synthetic
- No real client or DCS-sensitive data: remove references to real schools, staff, or clients
- No credentials, tenant names, IPs, or internal network details
- Safe Level 1 boundaries: ensure Level 1 tasks do not instruct harmful actions
- Realistic SLA and priority decisions: confirm impact and urgency fields are sensible
- Clear escalation points: every scenario with escalation must state next owner and evidence required
- Realistic ticket-note examples: include symptom, scope, safe checks, evidence, impact, recommended action, owner
- No duplicate IDs: run duplicate ID audit before merge
- No near-duplicate scenarios: check for near-duplicate content that could confuse learners
- No unsupported technical claims: avoid guaranteed vendor outcomes or claims requiring vendor-only access
- Consistent terminology: PSA, RMM, M365, UniFi, 3CX, backup, onboarding, escalation
